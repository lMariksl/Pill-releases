# Pill — релизы

Здесь лежат только готовые сборки Pill для Windows (без исходного кода).
Отсюда пилюля сама проверяет обновления и предлагает «Обновить».

**Установка:** скачайте `Pill.zip` из последнего релиза, распакуйте в любую папку
и запустите `Pill.exe`. Нужна Windows 10/11. SmartScreen может спросить:
«Подробнее» → «Выполнить в любом случае».
